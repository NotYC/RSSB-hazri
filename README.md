# Polyglot Attendance & Seniority Tracker

This is a distributed, polyglot microservices architecture designed to handle hierarchical employee management and high-frequency attendance logging.

## Project Structure
* `pure-api-backend/core`: NestJS Orchestration Layer (Public Gateway and State Manager)
* *(Future)*: FastAPI Intelligence Layer
* *(Future)*: Next.js Frontend & BFF Layer
* *(Future)*: Android App
